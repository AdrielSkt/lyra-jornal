# Jornal LYRA

Jornal semanal sobre música eletrônica e produção (House, Tech House, Melodic Techno/House, Afro/Organic), com curadoria da LYRA. Edições em português (`/pt/`) e inglês (`/en/`).

- Conteúdo: resumos próprios + links para as fontes originais. Nenhuma capa, foto ou áudio de terceiros.
- Charts: apenas fatos (posição, artista, faixa, label) com fonte e data.
- Correções ou pedidos de remoção: abra uma issue.

Instagram: @jornallyra (PT) · @the.lyra.journal (EN)
